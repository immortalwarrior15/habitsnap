# HabitSnap Meditation (Flutter)

Минималистичное мобильное приложение для медитации и релаксации (iOS/Android).

## Возможности
- Главный экран с кнопкой **«Начать медитацию»**.
- Выбор длительности: **5 / 10 / 15 / 30 минут**.
- Выбор фоновых звуков:
  - Дождь
  - Лес
  - Океан
  - Белый шум
  - Медитативная музыка
- Таймер:
  - Обратный отсчёт
  - Пауза/продолжение
  - Плавное завершение с колокольчиком
- Дополнительно:
  - Анимация дыхания (вдох/выдох)
  - Тёмная тема
  - Сохранение настроек (SharedPreferences)
  - Фоновое воспроизведение (just_audio_background)
  - Пресеты сценариев: Сон / Фокус / Антистресс
  - Регулировка громкости в UI
  - Мини-аналитика прогресса: сессии, минуты, дневной стрик
  - Адаптивное дыхание по пульсу (через Apple Health / Google Fit)

## Архитектура
Использована **чистая архитектура** с разделением на слои:
- `domain` — сущности и контракты
- `data` — реализации репозиториев
- `application` — state management (Riverpod, StateNotifier)
- `presentation` — экраны и виджеты
- `services` — аудиосервис

## Как проверить работоспособность приложения
### Базовая проверка
1. Запустите приложение на эмуляторе/устройстве.
2. Нажмите **«Начать медитацию»** — таймер должен пойти вниз.
3. Нажмите **«Пауза»** и снова старт — сессия должна корректно продолжиться.
4. Поменяйте длительность (5/10/15/30) — таймер должен сброситься на выбранное значение.
5. Поменяйте звук во время воспроизведения — звук должен переключиться без перезапуска приложения.

### Проверка пульса (Apple Health / Google Fit)
1. Включите переключатель **«Адаптировать под пульс»**.
2. Нажмите кнопку **«Проверить пульс сейчас»** на карточке пульса.
3. Выдайте доступ к данным здоровья (если запросится).
4. Убедитесь, что в карточке отображается:
   - BPM (не `—`),
   - статус **«актуальные данные»**,
   - обновлённый ритм дыхания (например, `4-5`, `4-6`).

## Важно про аудио
В `assets/audio/*.mp3` добавлены **mock-файлы** (заглушки). Замените их на реальные mp3 для корректного воспроизведения.

## Звуки из интернета
- Теперь приложение сначала пытается воспроизвести **онлайн-звук по URL**, а если сеть недоступна — автоматически переключается на локальный asset.
- URL звуков для дождя/леса/океана/белого шума/медитативной музыки заданы в `MeditationSound`.

## Пульс с AirPods / часов
- Приложение читает пульс из `Apple Health` (iOS) или `Google Fit` (Android) через пакет `health`.
- Любые устройства, которые пишут пульс в эти системы (Apple Watch, Garmin, Wear OS и т.д.), будут работать через общий канал данных.
- Для AirPods: если модель/приложение записывает пульс в Health/Fit, данные также будут подхватываться.
- Включите тумблер **«Адаптировать под пульс»** на главном экране и дайте разрешения на чтение пульса.
- На карточке пульса отображается статус канала данных: доступ не выдан / данные актуальны / данные устарели.
