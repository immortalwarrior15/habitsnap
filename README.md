# HabitSnap Meditation (Flutter)

Минималистичное мобильное приложение для медитации и релаксации (iOS/Android).

## Возможности
- Главный экран с кнопкой **«Начать медитацию»**.
- Выбор длительности: **5 / 10 / 15 / 30 минут**.
- Выбор фоновых звуков:
  - Дождь
  - Лес
  - Океан
  - Белый шум
  - Медитативная музыка
- Таймер:
  - Обратный отсчёт
  - Пауза/продолжение
  - Плавное завершение с колокольчиком
- Дополнительно:
  - Анимация дыхания (вдох/выдох)
  - Тёмная тема
  - Сохранение настроек (SharedPreferences)
  - Фоновое воспроизведение (just_audio_background)

## Архитектура
Использована **чистая архитектура** с разделением на слои:
- `domain` — сущности и контракты
- `data` — реализации репозиториев
- `application` — state management (Riverpod, StateNotifier)
- `presentation` — экраны и виджеты
- `services` — аудиосервис

## Запуск
```bash
flutter pub get
flutter run
```

## Важно про аудио
В `assets/audio/*.mp3` добавлены **mock-файлы** (заглушки). Замените их на реальные mp3 для корректного воспроизведения.
