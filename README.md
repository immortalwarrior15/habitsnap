# HabitSnap Meditation (Flutter)

Минималистичное мобильное приложение для медитации и релаксации (iOS/Android).

## Возможности
- Главный экран с кнопкой **«Начать медитацию»**.
- Выбор длительности: **5 / 10 / 15 / 30 минут**.
- Выбор фоновых звуков:
  - Дождь
  - Лес
  - Океан
  - Белый шум
  - Медитативная музыка
- Таймер:
  - Обратный отсчёт
  - Пауза/продолжение
  - Плавное завершение с колокольчиком
- Дополнительно:
  - Анимация дыхания (вдох/выдох)
  - Тёмная тема
  - Сохранение настроек (SharedPreferences)
  - Фоновое воспроизведение (just_audio_background)
  - Пресеты сценариев: Сон / Фокус / Антистресс
  - Регулировка громкости в UI
  - Мини-аналитика прогресса: сессии, минуты, дневной стрик

## Архитектура
Использована **чистая архитектура** с разделением на слои:
- `domain` — сущности и контракты
- `data` — реализации репозиториев
- `application` — state management (Riverpod, StateNotifier)
- `presentation` — экраны и виджеты
- `services` — аудиосервис

## Запуск
```bash
flutter pub get
flutter run
```

### Запуск в браузере (Chrome)
```bash
flutter config --enable-web
flutter devices
flutter run -d chrome
```

> Если в списке `flutter devices` нет Chrome, установите Google Chrome и перезапустите терминал.

## Важно про аудио
В `assets/audio/*.mp3` добавлены **mock-файлы** (заглушки). Замените их на реальные mp3 для корректного воспроизведения.

## Звуки из интернета
- Теперь приложение сначала пытается воспроизвести **онлайн-звук по URL**, а если сеть недоступна — автоматически переключается на локальный asset.
- URL звуков для дождя/леса/океана/белого шума/медитативной музыки заданы в `MeditationSound`.
